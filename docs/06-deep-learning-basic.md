# 06 - 深度学习基础

## 什么是深度学习

深度学习是机器学习的一个子集，通常使用多层神经网络从数据中自动提取特征。

## 深度学习适合什么数据

- 图像；
- 文本；
- 语音；
- 多模态数据。

## 常见模型

| 模型 | 用途 |
|---|---|
| DNN | 表格和简单分类 |
| CNN | 图像任务 |
| RNN / LSTM / GRU | 序列任务 |
| Transformer | NLP 和大语言模型 |
| GAN | 生成任务 |
| GNN | 图结构数据 |

## 特点

- 自动特征提取；
- 多层非线性变换；
- 需要大量数据和算力；
- 可解释性较弱。
