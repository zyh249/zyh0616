# 10 - 文本预处理

## NLP 任务

| 类型 | 例子 |
|---|---|
| NLU | 文本分类、情感分析、实体识别 |
| NLG | 机器翻译、摘要、问答 |
| 语音文字 | 语音识别、语音合成 |

## 文本预处理目标

准备模型需要的 X 和 Y：

- 文本数字化；
- 统一长度；
- 检查标签分布；
- 清洗脏数据；
- 提取文本特征。

## 主要环节

```text
分词
→ 词性标注 / 命名实体识别
→ 语料分析
→ n-gram 特征
→ 文本编码
→ 数据增强
```

## 编码方式

- One-hot；
- 词频编码；
- TF-IDF；
- 词嵌入；
- 预训练词向量。

## 长度规范

- 过长：截断；
- 过短：padding 补齐。
