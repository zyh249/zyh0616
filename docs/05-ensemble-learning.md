# 05 - 集成学习

## 核心思想

把多个弱学习器组合成一个强学习器。

## Bagging

特点：

- 有放回抽样；
- 模型并行训练；
- 平权投票或平均。

代表算法：随机森林。

## Boosting

特点：

- 使用全部样本；
- 后一个模型修正前一个模型的问题；
- 串行训练；
- 加权投票。

代表算法：GBDT、XGBoost。

## 对比

| 对比项 | Bagging | Boosting |
|---|---|---|
| 数据 | 有放回抽样 | 全部样本 |
| 训练 | 并行 | 串行 |
| 投票 | 平权 | 加权 |
| 代表 | 随机森林 | GBDT、XGBoost |
