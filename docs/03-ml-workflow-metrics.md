# 03 - 机器学习流程与评估

## 机器学习任务类型

| 任务 | 输出 | 例子 |
|---|---|---|
| 回归 | 连续数值 | 房价、薪资 |
| 分类 | 离散类别 | 是否垃圾邮件 |
| 聚类 | 自动分组 | 用户分群 |

## 监督学习与无监督学习

- 监督学习：有特征，也有标签。
- 无监督学习：有特征，没有标签。
- 半监督学习：少量有标签，大量无标签。
- 强化学习：通过奖励机制学习行动策略。

## 建模流程

```text
获取数据
→ 数据基本处理
→ 特征工程
→ 模型训练
→ 模型评估
→ 模型部署
```

## 分类评估指标

```text
准确率 = 正确数量 / 样本总数
精确率 = TP / (TP + FP)
召回率 = TP / (TP + FN)
F1 = 2 * precision * recall / (precision + recall)
```

## 回归评估指标

- MAE
- MSE
- RMSE
- R²
