# 04 - 常见机器学习算法

## 算法总览

| 算法 | 适合任务 | 核心思想 |
|---|---|---|
| KNN | 回归/分类 | 最近邻投票 |
| 线性回归 | 回归 | 用线性函数拟合数值 |
| 逻辑回归 | 分类 | 线性输出转概率 |
| 决策树 | 回归/分类 | 按特征划分数据 |
| 随机森林 | 回归/分类 | 多棵树投票 |
| XGBoost | 回归/分类 | 逐步修正错误 |
| K-means | 聚类 | 按距离分组 |

## 决策树

决策树是一种树形结构：

- 节点：特征判断；
- 分支：判断结果；
- 叶子：类别或预测值。

常见方法：

- ID3：信息增益；
- CART：基尼系数；
- 剪枝：缓解过拟合。
