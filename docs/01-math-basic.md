# 01 - 数学基础

## 学习目标

掌握 AI 学习中最常用的数学概念：指数、对数、线性函数、二次函数、导数、梯度和求和符号。

## 重点概念

### 指数与对数

指数和对数常用于概率模型、交叉熵、信息熵和损失函数。

```text
e^0 = 1
log(1) = 0
a^m * a^n = a^(m+n)
```

### 线性函数

```text
y = a + bx
```

机器学习中常写成：

```text
y_hat = b + w*x
```

其中 `b` 是偏置，`w` 是权重。

### 导数与梯度

导数可以理解为某点的斜率。机器学习中，梯度告诉模型参数应该往哪个方向更新。

```text
新参数 = 旧参数 - 学习率 * 梯度
```

## 练习

1. 用 Python 画 `y=x^2`。
2. 手算 `y=x^2` 在 `x=2` 处的导数。
3. 用循环实现求和。
4. 用 NumPy 计算 MSE。
