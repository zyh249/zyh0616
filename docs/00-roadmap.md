# 00 - AI 学习路线总览

本章是整个 AI 学习文档的入口。

## 学习顺序

```text
数学基础
→ 机器学习基本概念
→ 机器学习任务与建模流程
→ 传统机器学习算法
→ 集成学习
→ 深度学习与神经网络
→ CNN 图像任务
→ RNN / NLP 文本任务
→ 项目实践
```

## AI 四层关系

```text
人工智能 AI
└── 机器学习 ML
    └── 神经网络 NN
        └── 深度学习 DL
```

## 学习目标

学完这套资料后，你应该能：

- 解释 AI、ML、NN、DL 的关系；
- 理解样本、特征、标签、模型、算法、参数、超参数；
- 掌握机器学习建模流程；
- 看懂常见传统机器学习算法；
- 理解神经网络训练流程；
- 做简单的图像分类和文本处理项目。

## 推荐阅读顺序

1. 数学基础
2. 机器学习基础
3. 机器学习流程与评估
4. 常见机器学习算法
5. 集成学习
6. 深度学习基础
7. 神经网络基础
8. CNN
9. RNN 与 NLP
10. 项目实践
