# 09 - RNN 与 NLP

## 序列数据

序列数据的特点是后面的数据与前面的数据有关。

例子：

- 文本；
- 语音；
- 股票价格；
- 天气数据。

## RNN

RNN 是一种处理序列数据的神经网络，能够保留前面时间步的信息。

应用：

- 文本生成；
- 语言建模；
- 情感分析；
- 机器翻译；
- 时间序列预测。

## 词嵌入

词嵌入把 token 转为向量。

```python
nn.Embedding(num_embeddings=词表大小, embedding_dim=向量维度)
```

## 文本任务流程

```text
文本
→ 分词
→ 词表索引
→ 词嵌入
→ RNN / LSTM / GRU
→ 全连接层
→ 输出结果
```
