# 08 - 卷积神经网络 CNN

## 图像基础

彩色图像通常是 RGB 三通道数据，可以表示为：

```text
H x W x C
```

其中：

- H：高度；
- W：宽度；
- C：通道数。

## CNN 组成

```text
卷积层 → 激活层 → 池化层 → 全连接层
```

| 层 | 作用 |
|---|---|
| 卷积层 | 提取局部特征 |
| 激活层 | 增强非线性 |
| 池化层 | 降低尺寸和参数量 |
| 全连接层 | 输出分类结果 |

## 图像分类流程

```text
读取图片
→ 转为张量
→ 卷积提取特征
→ 池化降维
→ 全连接输出
→ 计算损失
→ 反向传播
```
