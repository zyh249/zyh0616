# 02 - 机器学习基础

## 学习目标

理解机器学习中的核心术语和基本思想。

## 传统编程 vs 机器学习

传统编程：

```text
规则 + 数据 → 答案
```

机器学习：

```text
数据 + 答案 → 规则
规则 + 新数据 → 新答案
```

## 数据术语

| 术语 | 含义 |
|---|---|
| 样本 | 一条完整数据 |
| 特征 | 用于预测的属性 |
| 标签 | 要预测的目标 |
| 训练集 | 用来训练模型 |
| 测试集 | 用来评估模型 |

## 模型术语

| 术语 | 含义 |
|---|---|
| 算法 | 学习规律的方法 |
| 模型 | 算法训练后的结果 |
| 参数 | 模型自动学习的值 |
| 超参数 | 人为设定的配置 |
| 损失函数 | 衡量预测与真实差距 |
| 性能指标 | 衡量模型效果 |

## 模型拟合

| 状态 | 表现 | 解决方向 |
|---|---|---|
| 欠拟合 | 训练差，测试也差 | 增加特征或模型能力 |
| 过拟合 | 训练好，测试差 | 正则化、剪枝、增加数据 |
| 合适拟合 | 训练和测试都较好 | 保持泛化能力 |
